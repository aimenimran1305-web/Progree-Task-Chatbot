# 🤖 Python Rule-Based Chatbot

A simple **rule-based chatbot built with Python** as part of the **Progree Python Programming Internship – Task 4**.

## 📌 Project Overview

This chatbot uses **keyword matching and intent detection** to understand user messages and provide appropriate responses.

It can answer basic questions about:

* Python
* Variables
* Functions
* Loops
* Automation
* General help

It also maintains a simple **session state** to track conversations and greeting/goodbye counts.

## ✨ Features

* Text normalization
* Keyword-based intent detection
* Multiple chatbot responses
* Session state management
* Greeting and goodbye handling
* Empty input handling
* Interactive command-line interface
* Unknown input handling

## 🛠️ Technologies Used

* Python 3
* `re` (Regular Expressions)

## 💬 Example

```text
==================================================
        PYTHON RULE-BASED CHATBOT
==================================================

Bot: Hello! I'm your Python assistant.
Bot: Type 'help' to see what I can do.
Bot: Type 'bye' or 'exit' to end the conversation.

You: hello
Bot: Hello! How can I help you today?

You: what is python
Bot: Python is a high-level programming language known for its simple syntax and wide range of applications.

You: what is a variable
Bot: A variable is used to store data in Python.

You: bye
Bot: Goodbye! Have a great day!
```
